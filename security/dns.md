# DNS

## DNSとは

ドメイン名（youtube.com など）とIPアドレスを紐づける仕組み。ブラウザはドメイン名のままではサーバーに接続できないので、まずDNSでIPアドレスを調べてから接続する。

## 偽のDNSサーバーは誰でも建てられる

「youtube.com → 攻撃者のサイトのIPアドレス」と答えるDNSサーバーは、誰でも建てられてしまう。

だから「**そのドメインの正しい情報を持っているのはどのサーバーか**」を、上位から案内してもらう仕組みがある。

## 登場人物

### DNSサーバーの種類

| 名前                 | 役割                                           | 例                                                          |
| -------------------- | ---------------------------------------------- | ----------------------------------------------------------- |
| **フルリゾルバー**   | PCの代わりに問い合わせて回る係                 | プロバイダーのDNSサーバー、8.8.8.8（Google）、1.1.1.1（Cloudflare） |
| **ルートサーバー**   | DNSの一番上。「`.com` はあそこに聞いて」と案内 | 世界に13系統ある                                            |
| **TLDのサーバー**    | 「youtube.com の担当はあそこ」と案内           | `.com` なら Verisign のサーバー                             |
| **権威DNSサーバー**  | そのドメインの正式な情報（IPアドレス）を持つ   | youtube.com なら ns1.google.com など                        |

TLD（Top Level Domain）は `.com` や `.jp` の部分のこと。


### レジストリとレジストラ

| 名前           | 役割                                   | 例                                     |
| -------------- | -------------------------------------- | -------------------------------------- |
| **レジストリ** | TLDのデータベースを管理する組織        | `.com` は **Verisign**、`.jp` は **JPRS** |
| **レジストラ** | ドメインの申し込みを受け付ける販売窓口 | お名前.com、GoDaddy など               |

## ドメインを取る時の流れ

1. **レジストラ**に「youtube.com を取りたい。このドメインの担当DNSサーバーはこれです」と申し込む
2. レジストラが**レジストリ**（`.com` なら Verisign）に登録する
3. 「youtube.com の担当は ns1.google.com など」という情報（**NSレコード**）が `.com` のサーバーに載る

`.com` のサーバーが持っているのは「**担当サーバーはどこか**」だけ。youtube.com のIPアドレスそのものは持っていない。IPアドレスを持っているのは権威DNSサーバー。

## ドメイン名からIPアドレスにたどり着くまで

```
0. PC が自分の中を確認（ブラウザ・OSのキャッシュ、hostsファイル）
   → 見つかればここで終わり
1. PC             → フルリゾルバー     : 「youtube.com のIPを教えて」
2. フルリゾルバー → ルートサーバー     : 「.com のことは .com のサーバーに聞いて」
3. フルリゾルバー → .com のサーバー    : 「youtube.com の担当は ns1.google.com などだよ」
4. フルリゾルバー → 権威DNSサーバー    : 「IPアドレスはこれ」
5. フルリゾルバー → PC                 : IPアドレスを返す
```

- PCが聞くのは**フルリゾルバーに1回だけ**。2〜4はフルリゾルバーがやる
- hostsファイルはPCの中にある「ドメイン名とIPアドレスの対応表」
- フルリゾルバーは調べた結果をしばらく覚えておく（**キャッシュ**）。覚えていれば2〜4を飛ばしてすぐ5を返す

## 案内であって証明ではない

この仕組みでわかるのは「**正しい情報を持っているのはどこか**」という道順だけ。届いた応答が本物かどうかを暗号的に証明しているわけではない。
