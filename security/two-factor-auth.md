# 2段階認証（2FA）

## 2段階認証とは

パスワードだけでは流出・フィッシング・総当たり攻撃などで突破される可能性があるため、異なる種類の認証要素を2つ組み合わせることでセキュリティを高める仕組み。

## 認証の3要素

| 要素 | 意味                     | 例                                                  |
| ---- | ------------------------ | --------------------------------------------------- |
| 知識 | 本人だけが知っていること | パスワード、PIN、秘密の質問                         |
| 所持 | 本人だけが持っているもの | スマホ(TOTP)、セキュリティキー、SMSを受け取れる端末 |
| 生体 | 本人自身の身体的特徴     | 指紋、顔認証、虹彩                                  |

ポイントは「異なる種類の要素を組み合わせること」。パスワードを2回入力しても同じ「知識」要素なので意味が薄い。パスワード（知識）+ TOTP（所持）のように異なる要素を組み合わせることで、片方が突破されてももう片方で守れる。

## 2段階認証の種類

| 方式             | 要素 | 仕組み                               |
| ---------------- | ---- | ------------------------------------ |
| SMS              | 所持 | 電話番号にコードを送信               |
| メール           | 所持 | メールアドレスにコードを送信         |
| TOTP             | 所持 | 認証アプリが時間ベースでコードを生成 |
| セキュリティキー | 所持 | USB等の物理デバイスを接続して認証    |
| プッシュ通知     | 所持 | スマホに通知が届き「承認」を押す     |
| 生体認証         | 生体 | 指紋・顔・虹彩など                   |

## 各方式のメリット・デメリット

### SMS

- メリット：特別なアプリ不要、電話番号さえあればOK
- デメリット：SIMスワップ攻撃で突破される可能性がある、通信費がかかる場合がある

### メール

- メリット：特別なアプリ不要、誰でも使える
- デメリット：メールアカウント自体が乗っ取られたら意味がない（パスワード使い回しのリスク）、届くまで数秒〜数分かかることがある

### TOTP

- メリット：オフラインでも使える、無料、サーバー側から送信する仕組みが不要
- デメリット：スマホを紛失すると復旧が大変、初期設定にQRコード読み取りが必要、設定できる人が限られる

### セキュリティキー

- メリット：最も安全、フィッシングにも強い
- デメリット：物理デバイスの購入が必要（数千円）、紛失したら詰む、対応していないサービスもある

### プッシュ通知

- メリット：コード入力不要でタップだけ、操作が楽
- デメリット：専用アプリやサービス基盤が必要、通知を疲れて適当に承認してしまうリスクがある

### 生体認証

- メリット：忘れない・なくさない、操作が最も楽
- デメリット：一度漏れたら変更できない、センサーが必要、精度の問題がある

## なぜTOTPを採用しているサービスが少ないのか

TOTPが技術的に劣っているのではなく、ビジネス的な判断が大きい。

- 一般ユーザーにとってQRコード読み取り→認証アプリ登録の手順はハードルが高い
- SMSやメールなら既に持っている情報（電話番号・メールアドレス）をそのまま使える
- 問い合わせやサポートコストの増加を避けたい

GitHubやAWSなど技術者向けのサービスではTOTPが当たり前に使えるのは、ユーザー層が設定に慣れているため。

## 補足：PayPay銀行のアプローチ

PayPay銀行はTOTPの「設定が難しい」という課題を、自社専用のTOTP生成アプリを提供することで解決している。

ユーザー側のメリット：

- QRコード読み取りが不要で「このアプリを開けばいい」だけになる
- 認証アプリの選び方や設定方法で迷うことがない

サービス側のメリット：

- サポートの統一：案内やマニュアルが1パターンで済む
- UXのコントロール：操作画面やフローを自由に設計できる
- セキュリティの管理：アプリ自体に生体認証を要求するなど、最低ラインを保証できる

金融サービスという性質上「ユーザー任せにできない」部分が多いため、多少コストをかけてでも自社でコントロールする判断をしている。
