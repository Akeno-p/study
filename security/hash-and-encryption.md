# ハッシュ化と暗号化

## ハッシュ関数とハッシュ値

```
入力 → [ハッシュ関数] → ハッシュ値（ハッシュ化された値）
        ↑ 仕組み           ↑ 結果
```

- **ハッシュ関数**: 変換を行う仕組み・計算方法のこと。SHA-256 などが代表例
- **ハッシュ値（ハッシュ化された値）**: その仕組みを通して出てきた結果のこと
- 「ハッシュ化する」= ハッシュ関数に入力を通すこと

パスワードの保存には bcrypt や Argon2 といったパスワード専用のハッシュ関数を使う。

## ハッシュ関数の2つの重要な性質

1. **一方向性**: 出力から入力を逆算できない
2. **決定性**: 同じ入力なら必ず同じ出力になる

セキュリティにおけるハッシュの価値は、ほぼこの2つの性質に集約される。

## ハッシュ化と暗号化の違い・使い分け

|              | ハッシュ化 | 暗号化           |
| ------------ | ---------- | ---------------- |
| 元に戻せるか | 戻せない   | 鍵があれば戻せる |
| 鍵の管理     | 不要       | 必要             |

使い分けの基準は「**サーバーが元の値を必要とするか**」。

| データ           | 保護方法   | 理由                                             |
| ---------------- | ---------- | ------------------------------------------------ |
| パスワード       | ハッシュ化 | 一致するか比較するだけでよく、元の値が不要       |
| アクセストークン | 暗号化     | 元の値をAPIに送る必要がある                      |
| TOTPの秘密鍵     | 暗号化     | 元の値でワンタイムパスワードを計算する必要がある |

「元に戻す必要がある。でも誰でも読めてはいけない」という要件への解が暗号化（[token-storage.md](token-storage.md)）。

## パスワード認証がハッシュ化で成立する仕組み

```
登録時:     「123」→ ハッシュ化 → 「aseg」→ DBに保存
ログイン時: 「123」→ ハッシュ化 → 「aseg」→ DBの「aseg」と一致 → OK
```

サーバーは「元に戻して照合」しているのではなく、**もう一度同じ計算をして結果が一致するかを見ている**だけ。決定性があるから成り立つ。

### ネットワーク上を流れるのは平文のパスワード

ハッシュ化は**サーバー側で行う**。ブラウザからは平文のパスワードがそのまま送られ、通信中の保護はHTTPSが担う（[http-https.md](../knowledge/web-technologies/http-https.md)）。

もしブラウザ側でハッシュ化してから送る設計にすると、**ハッシュ値そのものが実質のパスワードになってしまう**。傍受した「aseg」をそのまま送ればログインが通ってしまうため。

| 仕組み     | 守っている脅威           |
| ---------- | ------------------------ |
| HTTPS      | 通信中の傍受             |
| ハッシュ化 | DB漏洩時のパスワード流出 |

それぞれ**別の脅威**への対策で、組み合わせて使う。

### DBのハッシュ値が漏れても「使い道がない」

- 「aseg」から元の「123」は逆算できない（一方向性）
- 「aseg」をそのまま送っても、サーバーはそれを更にハッシュ化する（「aseg」→「xjfp」）ので不一致で弾かれる
- ユーザーが他サービスで使い回しているかもしれない「123」自体もバレない

攻撃者にとって「知ったところでどうにもならない」状態にできるのがハッシュ化の価値。

### 例外: Pass-the-Hash攻撃

「ハッシュ値で直接叩けるか」は**サーバーの設計次第**。WindowsのNTLM認証（古い方式）はハッシュ値をそのまま照合に使える設計だったため、DBやメモリから盗んだハッシュ値だけで、パスワードを知らずに認証を突破できた。設計上の欠陥として大きな問題になったが、レガシー互換のため今も完全には消えていない。

現代のWebフレームワークは必ず「受け取った平文をサーバー側でハッシュ化してから比較」するので、この攻撃は成立しない。
