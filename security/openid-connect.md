# OpenID Connect

「Googleでログイン」のようなソーシャルログインの仕組み。

```
OAuth 2.0       = 認可（何を許すか）
OpenID Connect  = OAuth 2.0 + 認証（誰であるか）
```

## OAuth だけではログインに使えない理由

OAuth のアクセストークンは「このアプリはデータを触ってよい」としか言っておらず、トークンの持ち主が誰かを保証していない。そのまま認証に使うと、別のアプリ向けに発行されたトークンを流用してなりすませてしまう。

## ID Token

OpenID Connect で追加されたトークン。ユーザーが誰かと、どのアプリ向けに発行したかが JWT 形式で書かれていて、発行したサービスの署名が付いている。アプリは、自分向けに発行されたものかを確かめてから、ユーザーを確認する。
