# XSS について

## XSS（クロスサイト・スクリプティング）とは

Webアプリケーションの不備により、攻撃者によって細工された悪意あるJavaScriptなどのスクリプトが、**一般ユーザーのブラウザ上で実行されてしまう脆弱性および攻撃手法**。

ブラウザは「表示しているWebサイトから提供された正規のスクリプト」と「攻撃者が不正に注入したスクリプト」を区別できない。そのため、ユーザーのブラウザ内で動作する権限をそのまま奪われ、様々な不正操作が行われる。

## なぜ起きるのか（発生原理）

Webページは「HTMLタグ（命令）」と「表示するデータ（文字列）」を組み合わせて作られる。

ユーザーの入力データや外部から受け取った文字列を画面に埋め込む際、特殊な文字（`<` や `>` など）の処理を怠ると、ブラウザが **「ただの文字列」を「HTMLタグや実行すべき命令」と誤解して解釈・実行してしまう** ことで発生する。

## XSSの3大分類

| 種類 | スクリプトの混入経路 | 仕組み・特徴 |
| :--- | :--- | :--- |
| **格納型 (Stored)**<br>*(蓄積型 / 持続型)* | **サーバーのデータベース** | 攻撃者が掲示板やSNS、プロフィール欄などにスクリプトを投稿し、DBに保存させる。その投稿を閲覧した不特定多数のユーザー全員の画面で自動的にスクリプトが実行される。最も被害規模が広がりやすい。 |
| **反射型 (Reflected)**<br>*(非持続型)* | **リクエスト（URLパラメータ等）** | 検索キーワードやエラー表示など、ユーザーのリクエスト内容をそのまま画面に表示（反射）する処理を悪用する。攻撃用パラメータを含んだ罠リンクを攻撃者が用意し、それを踏ませた特定の被害者に対してのみ発火させる。 |
| **DOM型 (DOM-based)** | **ブラウザ側のJavaScript環境 (DOM)** | サーバー側の処理を介さず、クライアント側（ブラウザ上）で動くJavaScriptがURLのパラメータやフラグメント（`#`）などの危険な値を読み取り、安全でない方法で画面（DOMツリー）へ追加した際に発火する。 |

## 主な被害内容

- **セッションハイジャック（アカウント乗っ取り）**
  - ブラウザに保持されているセッションCookieを攻撃者のサーバーへ送信し、認証を偽装して不正ログインを行う。
- **機密情報の窃取**
  - 画面上に表示されている個人情報、メッセージ履歴、入力フォームのクレジットカード情報などを盗み出す。
- **なりすましによる不正操作**
  - ログイン中のユーザーの権限で、勝手に投稿・送金・パスワード変更などのAPIやリクエストをブラウザから送信する。
- **画面の改ざん・フィッシング詐欺**
  - 画面を書き換えて本物そっくりの偽ログインフォームを表示し、ユーザーに再認証を促してIDやパスワードを盗み取る。

## 主な対策方法

### 1. HTMLエスケープ（根本対策）
動的に文字列をHTMLへ出力する際、HTMLの意味を持つ特殊文字をブラウザが解釈しない「文字実体参照」へ変換（無害化）する。

| 対象文字 | エスケープ後 |
| :---: | :---: |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `'` | `&#x27;` |

### 2. 安全なAPI・描画メソッドの使用
HTMLとして解釈・解析（パース）されるメソッドや構文を避け、純粋な「文字列データ（テキストノード）」としてブラウザに処理させるAPIを使用する。

### 3. サニタイズ（HTML入力を許容する場合）
リッチテキストエディタ等で一部のタグ（太字、リンク等）を許可する必要がある場合、危険なタグ（`<script>`、`<iframe>`）や危険な属性（`onload`、`onerror` などのイベントハンドラ、`javascript:` スキーム）のみを厳密に取り除く処理（消毒）を行う。

### 4. 多層防御（被害を軽減・防止する盾）
- **CookieのHttpOnly属性の設定**
  - セッション管理に用いるCookieに `HttpOnly` フラグを付与し、JavaScriptからの参照（`document.cookie`）をブラウザレベルで禁止する（セッションハイジャックの防止）。
- **CSP（Content Security Policy: コンテンツセキュリティポリシー）**
  - HTTPレスポンスヘッダーで、ブラウザに対してインラインスクリプトの実行禁止や、信頼できるソース以外の外部スクリプト読み込み禁止を指示する。
