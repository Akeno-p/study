# cssの記号

CSSで使われる記号を、種類ごとにまとめる。

```text
- → 名前や数字の一部（演算子ではない）
> → 直接の子を選ぶ（演算子）
```

## ✒️>（子セレクタ）

`>` は、直接の子要素だけを選ぶための記号。子結合子と呼ぶ。

```css
.list > li {
  color: red;
}
```

この場合、`.list` の直接の子である `li` だけが赤くなる。

ポイントは「直接の子（1階層下）だけ」という点。

```html
<ul class="list">
  <li>りんご</li>
  <li>みかん
    <ul>
      <li>温州みかん</li>
    </ul>
  </li>
</ul>
```

```text
りんご（直接の子）     → 赤くなる
みかん（直接の子）     → 赤くなる
温州みかん（孫）       → 赤くならない
```

## ✒️>とスペースの違い

`>` の理解は、スペース区切りとの比較がわかりやすい。

```css
.list > li {
  color: red;
}

.list li {
  color: red;
}
```

```text
.list > li → 直接の子だけ（1階層下だけ・狭い）
.list   li → 子孫すべて（何階層下でも・広い）
```

スペース区切りは子孫セレクタになり、階層に関係なく中の要素を全部選ぶ。
`>` は、1階層下だけに絞り込みたい時に使う。

## >の使い所

`>` は、入れ子になりやすい構造で、内側まで巻き込みたくない時に使う。

```css
.menu > li {
  border-bottom: 1px solid #ccc;
}
```

この場合、一番外側のメニュー項目だけに線が引かれ、サブメニュー側には影響しない。

スペース区切り（`.menu li`）だと、サブメニューの項目にまで線が付いてしまう。
狙った階層だけに当てたい時に `>` を選ぶ。
