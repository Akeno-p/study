# cssの変数

CSS変数は、値に名前を付けて保存し、使い回すためのしくみ。

正式には「カスタムプロパティ」と呼ぶ。

```text
-- → 値を作って保存する
var() → 保存した値を取り出して使う
```

## ✒️--（変数を作る）

`--` で始まる名前を付けて、値を保存する。

```css
:root {
  --main-color: red;
}
```

`--好きな名前: 値;` という形で書く。

通常のCSSと並べると、形は全く同じ。プロパティ名の部分が `--変数名` になっただけ。

```css
color: red; /* 普通のプロパティ */
--main-color: red; /* 変数の定義 */
```

`:` で区切って、最後に `;` を付けるのも普通のCSSと同じ。

## ✒️var()（変数を使う）

保存した値は `var()` で取り出す。

```css
p {
  color: var(--main-color);
}
```

`var(--main-color)` の部分が、保存した値（`red`）に置き換わる。

呼び出す時も、`--` を付けたフルネームで書く。

```css
color: var(base-font-size); /* 動かない（--が無い） */
color: var(--base-font-size); /* 正しい */
```

```text
定義： --base-font-size: 15px;
呼出： var(--base-font-size)
        ↑ 定義した名前をそのまま書く
```

## ✒️名前と用途は縛られない

変数は、ただ値を保存しているだけ。名前に「この用途専用」という縛りはない。

```css
:root {
  --base-font-size: 15px;
}

p {
  padding: var(--base-font-size);
}
```

この場合、`font-size` 用のつもりで作った変数を `padding` に使っても問題なく動く。

そのため、用途で縛らず `--space-md` のような中立的な名前にしておくと、使い回しやすい。

## ✒️フォールバック（保険の値）

`var()` には、変数が見つからなかった時の予備の値を2つ目に書ける。

```css
p {
  color: var(--main-color, black);
}
```

この場合、`--main-color` があればその値を、なければ `black` を使う。

## 補足:rootについて

`:root` は、ページ全体のいちばん外側を指すセレクタ（実質 `<html>`）。

```css
:root {
  --main-color: red;
  --base-space: 16px;
}
```

いちばん外側で変数を作っておくと、ページのどこからでも `var()` で呼び出せる。
全体で使う変数は `:root` に書くのが定番。
