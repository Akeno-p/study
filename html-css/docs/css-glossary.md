## セマンティッククラス

「見た目」ではなく「意味・役割」に基づいて名前を付けたCSSクラスのこと。

```html
<!-- ❌ 見た目ベース：red-text（赤い文字） -->
<p class="red-text">エラーが発生しました</p>

<!-- ⭕ 意味ベース：error-message（エラーメッセージ） -->
<p class="error-message">エラーが発生しました</p>
```

意味ベースの名前だと、「赤→青に変えたい」時もクラス名はそのままでCSSの値だけ直せばよく、HTMLを見ただけで役割が伝わる。

※ `<header>` `<nav>` などの「セマンティック要素（タグ）」とは別物。あちらはタグの話、こちらはclass名の話。
