# コマンド記号について

## |（パイプ）

コマンドの出力を次のコマンドの入力に渡す。コマンドをつなげて処理できる。

```bash
cat access.log | grep "ERROR"             # ログからERRORを含む行だけ抜き出す
cat access.log | grep "ERROR" | head -5   # さらに先頭5行だけ表示
```

## >（リダイレクト・上書き） >>（リダイレクト・追記）

コマンドの出力をファイルに書き込む。

- `>` → 上書き（既存の内容は消える）
- `>>` → 追記（既存の内容の後ろに追加される）

```bash
echo "hello" > sample.txt     # sample.txtに上書き
echo "world" >> sample.txt    # sample.txtに追記
```
