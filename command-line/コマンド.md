# コマンドについて

## コマンド早見表

| コマンド  | 意味                                       |
| --------- | ------------------------------------------ |
| `touch`   | 新しいファイルを作成する                   |
| `cat`     | ファイルの中身を表示する                   |
| `mkdir`   | 新しいディレクトリを作成する               |
| `cd`      | ディレクトリを移動する                     |
| `pwd`     | 現在のディレクトリのパスを表示する         |
| `ls`      | ディレクトリの中身を一覧表示する           |
| `mv`      | ファイルやディレクトリを移動・リネームする |
| `rm`      | ファイルやディレクトリを削除する           |
| `cp`      | ファイルやディレクトリをコピーする         |
| `tree`    | ディレクトリ構造をツリー形式で表示する     |
| `grep`    | ファイルの中から文字列を検索する           |
| `find`    | ファイルやディレクトリを名前で検索する     |
| `echo`    | 文字列を表示する・変数の確認に使う         |
| `clear`   | ターミナルの画面をクリアする               |
| `history` | 過去に実行したコマンドの履歴を表示する     |
| `which`   | コマンドのインストール場所を表示する       |

## オプションと引数

- **オプション（フラグ）**：コマンドの動作を変えるもの（`-p`、`-r` など）
- **引数（argument）**：コマンドの対象となるもの（ファイル名やディレクトリ名など）

```bash
mkdir -p dir1/dir2
```

- `mkdir` → コマンド
- `-p` → オプション
- `dir1/dir2` → 引数

## touch

新しいファイルを作成する。
正しくはファイルのタイムスタンプを更新するがファイルがない時は新規作成するというものだが、基本的に新しいファイルを作成する目的で使用される。

```bash
touch sample.txt
```

## cat

ファイルの中身を表示するコマンド。concatenate（連結する）の略。
複数ファイルを連結して表示したり、リダイレクトと組み合わせてファイルに書き込むこともできる。

サーバー上での作業やログ確認など、エディタを開かずにターミナル上でさっと中身を見たいときに使う。

```bash
cat sample.txt
```

### 主なオプション

| オプション | ロングオプション | 意味             |
| ---------- | ---------------- | ---------------- |
| `-n`       | `--number`       | 行番号を表示する |

## mkdir

新しいディレクトリ（フォルダ）を作成する。make directoryの略。

```bash
mkdir my_folder
```

### 主なオプション

| オプション | ロングオプション | 意味                                 |
| ---------- | ---------------- | ------------------------------------ |
| `-p`       | `--parents`      | 途中のディレクトリもまとめて作成する |

## cd

ディレクトリを移動する。change directoryの略。

```bash
cd path/to/dir   # 指定したディレクトリに移動
cd ..            # 一つ上の階層に戻る
cd ~             # ホームディレクトリに戻る
cd               # これだけでもホームディレクトリに戻れる
```

## pwd

現在のディレクトリのパスを表示する。print working directoryの略。

```bash
pwd
# 例: /Users/username/projects
```

## ls

ディレクトリの中身を一覧表示する。listの略。

```bash
ls
```

### 主なオプション

| オプション | ロングオプション | 意味                                                       |
| ---------- | ---------------- | ---------------------------------------------------------- |
| `-l`       | なし             | 詳細情報（権限、サイズ、更新日時など）を表示する。longの略 |
| `-a`       | `--all`          | 隠しファイル（`.`で始まるファイル）も表示する              |
| `-la`      | —                | `-l` と `-a` を組み合わせたもの                            |

※ `-la` のようにオプションはまとめて書ける。これは多くのコマンドで共通。

## mv

ファイルやディレクトリを移動する。moveの略。
名前の変更（リネーム）にも使う。

```bash
mv sample.txt dir1/       # ファイルを別のディレクトリに移動
mv old_name.txt new_name.txt  # ファイル名を変更
```

※ 移動先に同名のファイルがあると何も聞かずに上書きされるので注意。
※ 2つ目の引数が既存のディレクトリなら移動、それ以外ならリネームになる。

### 主なオプション

| オプション | ロングオプション | 意味                         |
| ---------- | ---------------- | ---------------------------- |
| `-i`       | `--interactive`  | 上書き前に確認する           |
| `-f`       | `--force`        | 確認なしで強制的に上書きする |

## rm

ファイルやディレクトリを削除する。removeの略。

```bash
rm sample.txt        # ファイルを削除
rm -r dir1/          # ディレクトリを中身ごと削除
```

※ 削除したファイルはゴミ箱に入らず完全に消える。
※ ディレクトリを削除するときは `-r` が必須。

### 主なオプション

| オプション | ロングオプション | 意味                           |
| ---------- | ---------------- | ------------------------------ |
| `-r`       | `--recursive`    | ディレクトリを中身ごと削除する |
| `-i`       | `--interactive`  | 削除前に確認する               |
| `-f`       | `--force`        | 確認なしで強制的に削除する     |

## cp

ファイルやディレクトリをコピーする。copyの略。

```bash
cp sample.txt copy.txt    # ファイルをコピー
cp sample.txt dir1/       # ディレクトリにコピー
cp -r dir1/ dir2/         # ディレクトリを中身ごとコピー
```

※ コピー先に同名ファイルがあると上書きされる。
※ ディレクトリをコピーするときは `-r` が必須。

### 主なオプション

| オプション | ロングオプション | 意味                             |
| ---------- | ---------------- | -------------------------------- |
| `-r`       | `--recursive`    | ディレクトリを中身ごとコピーする |
| `-i`       | `--interactive`  | 上書き前に確認する               |
| `-f`       | `--force`        | 確認なしで強制的に上書きする     |

## tree

ディレクトリ構造をツリー形式で表示する。

※ macOSには標準で入っていないため `brew install tree` でインストールが必要。

```bash
tree          # 全階層を表示
tree -L 1     # 1階層分だけ表示
tree -L 2     # 2階層分まで表示
```

### 主なオプション

| オプション | 意味                         |
| ---------- | ---------------------------- |
| `-L n`     | 表示する階層の深さを指定する |
| `-a`       | 隠しファイルも表示する       |
| `-d`       | ディレクトリのみ表示する     |

## grep

ファイルの中から指定した文字列を検索する。Global Regular Expression Printの略。

```bash
grep "hello" sample.txt     # ファイルから検索
grep -rn "hello" .          # 現在のディレクトリ以下を行番号付きで再帰検索
```

※ 検索文字列にスペースを含む場合は `""` で囲む必要がある。

### 主なオプション

| オプション | ロングオプション | 意味                             |
| ---------- | ---------------- | -------------------------------- |
| `-r`       | `--recursive`    | ディレクトリ内を再帰的に検索する |
| `-i`       | `--ignore-case`  | 大文字・小文字を区別しない       |
| `-n`       | `--line-number`  | 一致した行の行番号を表示する     |
| `-c`       | `--count`        | 一致した行数だけ表示する         |

## find

ファイルやディレクトリを名前で検索する。
※ findは名前で検索ではなく、`find 検索場所 条件` という構造。`-name` 以外にも `-type f`（ファイルのみ）、`-type d`（ディレクトリのみ）などの条件がある。

```bash
find . -name "sample.txt"    # 現在のディレクトリ以下からファイル名で検索
find . -name "*.txt"         # .txtファイルを全部探す
```

## echo

文字列をそのまま表示する。変数の確認やリダイレクトでファイルに書き込むときに使う。

```bash
echo "hello"                 # hello と表示される
echo $HOME                   # 変数の中身を表示
echo "hello" > sample.txt    # ファイルに書き込む（上書き）
echo "world" >> sample.txt   # ファイルに追記
```

## clear

ターミナルの画面をクリアする。

```bash
clear
```

※ `Ctrl + L` でも同じことができる（上スクロールで過去の出力は残る）。
※ `Cmd + K` だとスクロールバッファごと消えるが、実用上の差はほぼない。

## history

過去に実行したコマンドの履歴を表示する。

```bash
history          # 全履歴を表示
history 10       # 直近10件を表示
```

※ `↑` キーで直前のコマンドをさかのぼることもできる。

## which

コマンドがどこにインストールされているか（ファイルパス）を表示する。
同じコマンドが複数入っているときに、今どれが使われているか確認するのに便利。

```bash
which python
# 例: /usr/bin/python（仮想環境の有無で変わる）
```
