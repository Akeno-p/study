# データベースの基礎知識

## DBサーバーを別途立てる理由

個人用・小規模ならSQLiteのようにアプリケーションサーバー上にDBを同居させることができる。しかし規模が大きくなると以下の理由でDBを別サーバーに分離する。

- **同時書き込みへの対応**: PostgreSQLやMySQLは行単位でロックできるため、多数のユーザーが同時に書き込んでも性能が落ちにくい
- **アプリサーバーの水平分散**: アプリサーバーを複数台に増やしても、全サーバーが同じDBサーバーに接続すればデータが一元管理できる
- **ディスク容量の独立**: アプリのログや画像とDBのディスクを分けることで、互いに容量を圧迫しない

※ ロックとは？　データを変更する時に、同時に同じデータを変更できてしまうと不整合が生まれる可能性があるため、一人だけが読み書きできるようにブロックすること。

## 主なデータベースの種類

| DB         | 種類           | 特徴                                      |
| ---------- | -------------- | ----------------------------------------- |
| SQLite     | ファイルベース | サーバー不要。個人・小規模向け            |
| PostgreSQL | サーバー型     | 高機能。大規模・本番環境で広く使われる    |
| MySQL      | サーバー型     | Webアプリで広く普及。シンプルで扱いやすい |

## Turso / libSQL

SQLiteをベースに拡張したホスティングサービス。

- SQLiteの軽さはそのままに、ネットワーク越しのアクセスを可能にした
- 世界中にレプリカを配置して読み取りを高速化できる
- SQLiteベースなのでリソース消費が少なく、格安で運用できる
