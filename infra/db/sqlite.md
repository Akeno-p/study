# SQLite

ファイルベースのデータベース。DBサーバーを別途立てる必要がなく、アプリケーションサーバー上に`.sqlite3`ファイルとして配置するだけで動作する。

## 特徴

- DBサーバー不要。ファイル1つで完結する
- 軽量でセットアップが簡単
- Djangoのデフォルトのデータベース

## 向いているケース

- 個人用アプリ、少人数のアプリ
- プロトタイプ・開発環境

## 向いていないケース

- 同時書き込みが多い（ファイル全体をロックするため、順番待ちが発生する）
- アプリサーバーを複数台に分散する構成（各サーバーに別々のファイルができてデータがバラバラになる）
- デプロイ時にファイルシステムがリセットされるホスティング（Heroku, Cloud Runなど）

## 容量

- SQLite自体の仕様上の最大サイズは約281TB（実質無制限）
- 実際の上限はサーバーのディスク容量に依存する
- SQLiteファイルはアプリやログなどとディスクを共有しているため、アプリ全体でディスク容量を食い合う形になる
