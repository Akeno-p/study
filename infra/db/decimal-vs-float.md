# decimal　と float の違い

## 結論

decimalは正確だけど重い。
floatは誤差が生まれる可能性があるけど軽い。
迷ったらdecimalを使おう。

## floatの２進数への変換方法

1. 整数部分と小数部分に分ける。
2. 整数部分を2進数に直す。
3. 小数部分も2進数に直す。
4. 小数部分に２をかける
5. 結果の整数部分に0か1を記録する
6. 小数部分に２をかける
7. 小数部分が0になるまで繰り返す。
8. 整数と小数の2進数を合体させる。
9. 整数部分が一桁になる位置に小数点を移動させ、何桁動かしたか記録する。
10. 最初の1bitに符号、次の11bitに指数、残りの52bitに仮数をおいて完成。

###　実際に計算してみる(例：6.3)

#### 1. 整数部分と小数部分に分ける。

整数 6
小数 3

#### 2. 整数部分を２進数に直す。

6の２進数は 110

#### 3. 小数部分も２進数に直す

※ 無限に続くことがある。
| 計算 | 結果 | 整数部分 | |
| --- | --- | ------- | -- |
| 0.3 × 2 | 0.6 | 0 | |
| 0.6 × 2 | 1.2 | 1 | |
| 0.2 × 2 | 0.4 | 0 | |
| 0.4 × 2 | 0.8 | 0 | |
| 0.8 × 2 | 1.6 | 1 | |
| 0.6 × 2 | 1.2 | 1 |　２度目の登場。ここからループ |

結果：010011001100110011.....となる

#### 4. 整数と少数を合体させる。(64bitの場合max52桁)

110.0100110011001100110011001100110011001100110011001100
※ 打ち切られるため少し値がズレる

#### 5. 整数部分が一桁になる位置に小数点を移動させ、何桁動かしたか記録する。

2桁ずらした。
1.100100110011001100110011001100110011001100110011001100

#### 6. 最初の1bitに符号、次の11bitに指数、残りの52bitに仮数をおいて完成。

整数なので 0
2桁ずらしたので 2。それに バイアス(+1023)をたして2進数に直す。
仮数は最初の1をとって 100100110011001100110011001100110011001100110011001100 になる。

合体して
0 10000000001 1001001100110011001100110011001100110011001100110011

※ 指数が11bitで表現できないときはエラーになる。

## floatの計算が早い理由

- CPUにfloatの計算をするところがあるから

## decimalの数値の表し方

floatのように「小数そのもの」を2進数へ変換するのではなく、
**小数点を消して整数にしてから、その整数を2進数にする**。

1. 小数点を消して、整数の列にする。
2. 小数点を何桁動かしたか（scale）を記録する。
3. 整数を2進数に直す。
4. 決まった桁数の枠に、符号・scale・仮数をおいて完成。
   （例：.NET の decimal ＝ 128bit。符号1bit / scale用8bit / 仮数用96bit / 残りは未使用の0）

###　実際に表してみる(例：6.3 を .NET decimal で保存)

#### 1. 小数点を消して整数の列にする。

6.3 → 63

#### 2. 小数点を何桁動かしたか記録する。

1桁動かした → scale = 1

#### 3. 整数を2進数に直す。

63 → 111111（整数はピッタリ変換できる）

#### 4. 決まった枠に 符号・scale・仮数 をおいて完成。

＋なので 符号は 0
scaleは 1 → 8bitで 00000001
仮数は 63 → 96bitで 0...0111111

実際に保存される128bit（区切りの空白は見やすさ用。本当は詰まっている）

符号(1) | 未使用(7) | scale(8bit) | 仮数(96bit)
0 0000000 00000001 000...000111111

※ floatと違い「何bit目が何か」は桁数で決まっている（区切り記号はない）。
※ 小数を直接2進数にしないので打ち切りが起きず、値がズレない。

## decimalの計算が遅い理由

- CPUにdecimal専用の計算回路がないから
- ソフトウェア（プログラム）で桁ごとに計算するから
- 正確さのため桁数が可変で、処理する手順が多いから
