# ER図はなぜ書くのか

ER図とは、テーブル・カラム・リレーションを図にしたもの。

## 目的は「後で見やすくするため」ではない

ER図の本命の目的は、**コードを書く前にDBの構造を確定・検証すること**にある。「後から見てわかりやすくするため」にやるものではない。

## テキストでの洗い出しとER図の役割分担

DB設計は「テキストでエンティティ・属性を書き出す → ER図にする」という順で進めるのが自然。両者は役割が違う。

| 段階             | 役割                                                         |
| ---------------- | ------------------------------------------------------------ |
| テキスト洗い出し | 何があるか（エンティティ・属性）を並べる                     |
| ER図             | それらがどう繋がるか（リレーション）、過不足はないかを詰める |

テキストの箇条書きではリレーションを詰めずらい。

## カーディナリティ（多重度）とは

エンティティ同士の「数の関係」のこと。「1人のユーザーは複数の投稿を持つ」のように、片方から見て相手が何個ありうるかを表す。決めることは2つだけ。

- **最小はいくつか**: 0 か 1（＝任意か必須か）
- **最大はいくつか**: 1 か 多

この 2 × 2 で、カーディナリティは4パターンしかない。

## クロウフット記法(Crow's Foot Notation)の記号の意味

ER図では線の端の記号でカーディナリティを表す。この「鳥の足」に見える記法をクロウフット記法と呼ぶ。パーツは3つ。

| パーツ  | 意味         |
| ------- | ------------ |
| `\|`    | 1            |
| `o`     | 0            |
| `{` `}` | 多（鳥の足） |

記号は1つの側につき2つ並べ、置く位置で意味が変わる。

| 位置               | 表すもの                          |
| ------------------ | --------------------------------- |
| 箱に近い側（内側） | 最大いくつか（1 か 多）           |
| 線に近い側（外側） | 最小いくつか（0＝任意 / 1＝必須） |

この読み方を当てはめると、4パターンはこうなる。

| 記号   | 最小 | 最大 | 意味       |
| ------ | ---- | ---- | ---------- |
| `\|\|` | 1    | 1    | ちょうど1  |
| `o\|`  | 0    | 1    | 0 または 1 |
| `\|{`  | 1    | 多   | 1以上      |
| `o{`   | 0    | 多   | 0以上      |

※ `o{` ↔ `}o` のように左右で向きが反転した書き方があるが、意味は同じ。線のどちら側に置くかで見た目が鏡になるだけ。

※ 1対1（`\|\|`）で棒が2本なのは、「最大1（内側）」と「最小1＝必須（外側）」を別々に表しているため。

## 型の書き方

ER図に型を書くときは細かい型名まで厳密に書く必要はない。
設計の意図が伝わればいい。

### よく使用される型の書き方

| 意図         | ER図に書く型        | djangoのフィールド           | postgreSQL               |
| ------------ | ------------------- | ---------------------------- | ------------------------ |
| 整数         | int                 | IntegerField                 | integer                  |
| 大きな整数   | bigint              | BigAutoField,BigIntegerFiedl | bigint                   |
| 短い文字列   | varchar,varchar(10) | CharField(max_length=10)     | varchar(10)              |
| 長い文字列   | text                | TextField                    | text                     |
| 真偽値       | boolean             | BooleanField                 | boolean                  |
| 日時         | datetime            | DetaTimeField                | timestamp with time zone |
| 小数(正確な) | decimal             | DecimalField                 | numeric                  |
| 小数         | float               | FloatField                   | duble precision          |
