# 自分のサーバーの手前に置くサービス（CDN・WAF・Cloudflare など）

自分のサーバーの手前に置いて、リクエストを代わりに受け取り、後ろに中継する「ついでに」いろいろな機能を提供してくれるサービス。


```text
ブラウザ -> 手前に置くサービス -> Webサーバー -> アプリケーションサーバー -> DBサーバー
            └ サービス事業者が提供    └────────────── 自分で用意 ──────────────┘
```

## 手前に置くものの総称: リバースプロキシ

サーバーの手前に立って、利用者からのリクエストを代わりに受け取り、後ろのサーバーに中継するもの全般をリバースプロキシと呼ぶ。

手前に置くサービスは、仕組みとしてはどれもリバースプロキシで、「中継のついでに何をするか」が違うだけ。

| 種類             | 中継のついでにやること                                             |
| ---------------- | ------------------------------------------------------------------ |
| CDN              | 静的ファイルのコピーを保存しておき、持っていれば自分で返す         |
| ロードバランサー | 中継先を、複数の機械の中から選ぶ。停止している機械には振り分けない |
| WAF              | 中継する前に、攻撃かどうかを検査する                               |
| DDoS対策         | 大量アクセスでサーバーを使えなくする攻撃を、手前で受け止める       |

※ Webサーバーとアプリケーションサーバーを立て、静的ファイルをWebサーバーが返す構成にした場合、
アプリケーションサーバーから見ればWebサーバーは手前に置かれた中継役なので、仕組みとしてはリバースプロキシに含まれる。

### 会話での呼び方

会話で「リバースプロキシ」と言われたらwebサーバーを指していることが多いので、cloudflareのCDNを使用していることを言いたいのなら、「cloudflareのCDNを置いてます。」と言ったほう伝わりやすい。
