# ファイアウォール

外から届いた通信を、どのポートあてかを見て、通すか止めるかを決める仕組み。

```text
外からの通信 -> ファイアウォール
                 ├ 許可したポートあて -> 通す   -> プログラムに届く
                 └ それ以外           -> 止める -> 届かない
```

## なぜ必要か

### 開いているポートには、誰でも通信を送れる

プログラムがポートで通信を待っていると、インターネット上の誰でもそこに通信を送れる。

インターネット上では、開いているポートを探して回るプログラムが常に動いている。
見つかると、パスワードを総当たりで試されたり、プログラムの弱点（脆弱性）を突かれたりする。
開いているポートが多いほど、攻撃される入口が増える。

## 止めるのは入ってくる通信だけ

サーバーから外へ出ていく通信は、基本的にそのまま許可する。サーバー自身も、パッケージのダウンロードなどで外にアクセスする必要があるため。

ファイアウォールが防ぎたいのは「知らない相手から話しかけられること」なので、サーバーから始める通信は止めなくてよい。

出ていった通信への返事は「入ってくる通信」になるが、止まらない。ファイアウォールが「サーバーから始めた通信への返事」だと覚えていて、自動で通すため。

## サーバーの中の通信は関係ない

同じサーバーの中のプログラム同士の通信は、ファイアウォールで止まらない。だから、サーバーの中のプログラムからしか使わないポートは、外に開ける必要がない。
