# サーバーの基礎知識

## サーバーの種類

| 種類                     | 説明                                                       | 例                      |
| ------------------------ | ---------------------------------------------------------- | ----------------------- |
| 物理サーバー             | 自分でサーバー機を用意して運用する                         | 自宅サーバーなど        |
| VPS                      | 物理サーバーを仮想的に分割し、その1台を借りる              | ConoHa VPS, さくらVPS   |
| クラウドプラットフォーム | サーバー・DB・ストレージなどを部品単位で組み合わせて使える | AWS, GCP, Azure         |
| PaaS                     | デプロイやインフラ管理を自動化してくれるサービス           | Render, Railway, Heroku |

## VPS（Virtual Private Server）

物理サーバーの中に仮想的なサーバーを複数台作り、そのうちの1台を借りる形式。利用者側からは独立した1台のサーバーに見える。

- サーバーの用意は不要だが、OSの設定・ソフトのインストール・セキュリティ対策は全て自分でSSHで接続して操作する
- インフラの基礎（Linux, Nginx, SSL, デプロイ）を一通り学べる

## クラウドプラットフォーム（AWS等）

サーバーだけでなく、様々なサービスを組み合わせて使えるインフラの総合プラットフォーム。

### AWSの主なサービス例

| サービス | 役割                          |
| -------- | ----------------------------- |
| EC2      | サーバーを借りる（VPSに近い） |
| RDS      | DBサーバーを借りる            |
| S3       | ファイル置き場（画像など）    |
| Lambda   | サーバーなしでコードだけ実行  |

## PaaS（Render等）

デプロイやサーバー管理を自動化してくれるサービス。手軽だが、裏側で何が起きているか分かりにくい。

- デプロイが簡単（GitHubと連携するだけで動く場合もある）
- ファイルシステムがリセットされるサービスではSQLiteが使えない場合がある
