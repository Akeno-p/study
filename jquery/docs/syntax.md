# jQueryの書き方

## 基本構文

```js
$("セレクタ").メソッド(引数);
```

セレクタはダブルクオーテーション`""`で囲う。シングル`''`でもいい。

## セレクタの書き方

| 対象  | 書き方               | 例                         |
| ----- | -------------------- | -------------------------- |
| タグ  | そのまま             | `$("h1").hide();`          |
| id    | #をつける(cssと同じ) | `$("#text-title").hide();` |
| class | .をつける(cssと同じ) | `$(".text-base").hide();`  |
