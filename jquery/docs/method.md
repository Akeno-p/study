# jQueryメソッド一覧

**メソッドチェーン**
jQueryのメソッドは基本的にメソッドをつなげて書くことができる。

```js
$("h1").css("color", "red").text("Hello!").fadeOut();
```

## 表示・非表示

| メソッド    | 説明                                                         |
| ----------- | ------------------------------------------------------------ |
| hide()      | 隠す                                                         |
| show()      | 隠れてたものを表示する(cssのdisplay:none;を見える状態にする) |
| fadeOut()   | ゆっくり隠す                                                 |
| fadeIn()    | ゆっくり見せる                                               |
| slideUp()   | 下から隠す                                                   |
| slideDown() | 上から見せる                                                 |

## 内容の変更

| メソッド       | 説明                     |
| -------------- | ------------------------ |
| text("文字列") | htmlのテキストを変えれる |
| html("HTML")   | htmlを書き換えれる       |

## スタイルの変更

| メソッド                 | 説明                          |
| ------------------------ | ----------------------------- |
| css("property", "value") | cssを当てれる                 |
| addClass("クラス名")     | クラスを追加する(.はいらない) |
| removeClass("クラス名")  | クラスを削除する(.はいらない) |

## 要素の探索

| メソッド             | 説明                                   |
| -------------------- | -------------------------------------- |
| find("セレクタ")     | 子孫要素すべてから探す（深い階層もOK） |
| children("セレクタ") | 直下の子要素だけから探す（1階層だけ）  |

## イベント

| メソッド                  | 説明                                                                             |
| ------------------------- | -------------------------------------------------------------------------------- |
| hover(function, function) | マウスが乗ったとき(第一引数)・離れたとき(第二引数)の処理を設定できる(引数は関数) |
