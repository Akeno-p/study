# jQueryのコールバックと関数の渡し方

## メソッドの引数パターン

```js
$("セレクタ").メソッド名(引数);
```

引数には色々なパターンがある。

functionを渡す場合

```js
$("p").click(function () {});
```

引数なしの場合

```js
$("p").hide();
```

値を渡す場合

```js
$("p").css("color", "red");
```

## アロー関数は使える？

使える。がjqueryではfunctionのthisの方が相性がいい

### functionの場合

jQueryがコールバックを呼ぶとき、thisをイベント対象の要素に書き換えてくれる。

```js
$("p").click(function () {
  $(this).hide(); // クリックしたpが消える
});
```

### アロー関数の場合

アロー関数は定義された場所の外側のスコープのthisをそのまま使う。
jQueryがthisを書き換えようとしても無視される。

```js
$("p").click(() => {
  $(this).hide(); // 意図通りに動かない(thisが要素を指さない)
});
```
