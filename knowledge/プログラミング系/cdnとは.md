# CDNと外部CSSの読み込み

## 外部からCSSを読み込むとは

ローカルにあるCSSファイルではなく、インターネット上のURLからCSSを読み込むこと。

例:

```html
<link rel="stylesheet" href="https://example.com/style.css" />
```

これは「外部URLからCSSを読み込んでいる」と言える。

ただし、このURLの配信元がCDNとは限らない。

## CDNとは

CDNは `Content Delivery Network` の略。

CSS、JavaScript、画像、動画などのファイルを、速く安定して配信するためのサーバー網のこと。

普通のWebサーバーにファイルを置く場合は、ユーザーはそのサーバーへ直接取りに行く。

```text
ユーザーのPC -> Webサーバー
```

CDNの場合は、複数の地域に配信用サーバーがあり、ユーザーに近いサーバーからファイルを配信できる。

```text
ユーザーのPC -> 近くのCDNサーバー
```

## 外部URLから読み込むこととCDNの違い

「外部URLからCSSを読み込む」と「CDNからCSSを読み込む」は、厳密には別の話。

- 外部URLから読み込む: ローカルではなく、インターネット上のCSSを読み込むこと
- CDNから読み込む: CDNで配信されているCSSを読み込むこと

つまり、外部URLから読み込んでいても、配信元が普通のWebサーバーならCDNとは限らない。

## 言い方

広い意味で言うなら、次の表現が分かりやすい。

- 外部CSSを読み込む
- 外部URLからCSSを読み込む
- インターネット上のCSSを読み込む

配信元がCDNだと分かっている場合は、次のように言える。

- CDN経由でCSSを読み込む
- CDNで配信されているCSSを読み込む

「CDNから持ってくる」という言い方も会話ではよく使われる。

ただし、厳密にはCDNは「ファイルの場所」ではなく「配信の仕組み」なので、「外部URLから読み込む」と言った方が広い意味では正確。

## まとめ

ローカルに置かずにインターネット上のCSSを読み込むこと全般は、「外部URLからCSSを読み込む」と言うのが一番ズレにくい。

その外部URLの配信元がCDNである場合に、「CDN経由で読み込む」と言える。
