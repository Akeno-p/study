# CDNについて

CDN は Content Delivery Network の略。

**各地に置いたサーバーにファイルのコピーを保存しておき、利用者に一番近いサーバーから返す仕組み。**

```text
CDNなし: 北海道の利用者 -> 東京のサーバー
CDNあり: 北海道の利用者 -> 北海道のCDNサーバー（コピーを持っている）
```

## 流れ

1. 利用者が一番近い CDN のサーバーにリクエストを送る
2. コピーを持っていれば、そのまま返す
3. 持っていなければ元のサーバーに取りに行き、利用者に返すと同時にコピーを保存する。次からは 2 になる

## 利点

| 利点                     | 理由                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 表示が速くなる           | 近いサーバーから届くので、届くまでの時間が短い               |
| 元のサーバーの負担が減る | 2回目以降は CDN が返すので、元のサーバーにリクエストが来ない |

## 対象は静的ファイル

CSS、JavaScript、画像、動画など、**誰に返しても同じ内容のファイル**だけ。ログイン後のページのように人によって内容が違うものはコピーできない。

## 使われ方は2種類

| 使われ方                   | 例              | 元のサーバー        |
| -------------------------- | --------------- | ------------------- |
| 自分のサーバーの手前に置く | Cloudflare      | 自分の Web サーバー |
| ライブラリを配る           | jsDelivr、cdnjs | 配布サービスのもの  |


## 「CDNから読み込む」とは

Bootstrap などのライブラリの説明でよく出てくる言い方。

**ダウンロードして自分のプロジェクトに置かずに、ネット上の URL から読み込むこと。**

| 方法                 | 内容                                                                          |
| -------------------- | ----------------------------------------------------------------------------- |
| ダウンロードして使う | ファイルをダウンロードして、自分のプロジェクトに置く                          |
| CDN から読み込む     | 自分では置かず、公開されている URL を `<link>` や `<script>` に書くだけで使う |

例:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" />
```

## なぜ「CDN」と呼ぶのか

ライブラリを配っているサービス（jsDelivr、cdnjs など）が CDN だから。
CDN 自体は「利用者に近い場所のサーバーからファイルを返す配信の仕組み」で、「ネットから取ってくる」ことを CDN と呼ぶわけではない
