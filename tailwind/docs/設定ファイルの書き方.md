# 設定ファイルの書き方（v4）

## v3 と v4 の違い

| バージョン | 設定方法          | 設定ファイル                                          |
| ---------- | ----------------- | ----------------------------------------------------- |
| v3 以前    | JavaScript で書く | `tailwind.config.js`（`npx tailwindcss init` で生成） |
| v4         | CSS で書く        | `input.css` に `@theme` を書く（設定ファイル不要）    |

v4 では `tailwind.config.js` は廃止。ネット上の記事に `npx tailwindcss init` と書いてあったら v3 の情報。

## 基本の書き方

`input.css` に `@theme` ブロックを追加する。

```css
@import "tailwindcss";

@theme {
  /* ここに設定を書く */
}
```

`@import "tailwindcss";` の後ろに置く。

## `@theme` の中身

CSS カスタムプロパティ（変数）の形式で書く。

```
--{カテゴリ}-{名前}: 値;
```

カテゴリ名を合わせれば、Tailwind が自動的に対応するクラスを生成する。

## 書ける内容と主要カテゴリ

### カラー

```css
@theme {
  --color-primary: #0ea5e9;
  --color-primary-light: #38bdf8;
  --color-primary-dark: #0284c7;
}
```

`bg-primary`、`text-primary-light`、`hover:bg-primary-dark` 等のクラスが使えるようになる。

### フォント

```css
@theme {
  --font-sans: "Noto Sans JP", sans-serif;
}
```

`font-sans` クラスのフォントが変わる。

### サイズ・余白

```css
@theme {
  --spacing-128: 32rem;
  --width-content: 960px;
  --height-header: 64px;
}
```

`p-128`、`w-content`、`h-header` 等のクラスが追加される。

### ブレークポイント

```css
@theme {
  --breakpoint-sm: 480px;
  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
}
```

`md:text-lg` 等のレスポンシブの境界値を変更できる。

## カテゴリ一覧

| カテゴリ         | 生成されるクラス例              |
| ---------------- | ------------------------------- |
| `--color-*`      | `bg-*`, `text-*`, `border-*`    |
| `--font-*`       | `font-*`                        |
| `--spacing-*`    | `p-*`, `m-*`, `gap-*`           |
| `--width-*`      | `w-*`                           |
| `--height-*`     | `h-*`                           |
| `--min-width-*`  | `min-w-*`                       |
| `--min-height-*` | `min-h-*`                       |
| `--max-width-*`  | `max-w-*`                       |
| `--max-height-*` | `max-h-*`                       |
| `--breakpoint-*` | `sm:`, `md:`, `lg:`             |
| `--radius-*`     | `rounded-*`                     |
| `--shadow-*`     | `shadow-*`                      |
| `--text-*`       | `text-sm`, `text-lg` 等のサイズ |
| `--tracking-*`   | `tracking-*`（字間）            |
| `--leading-*`    | `leading-*`（行間）             |
| `--z-*`          | `z-*`（z-index）                |
| `--opacity-*`    | `opacity-*`                     |

全部覚える必要はない。「`--{CSS プロパティ名に近いもの}-{好きな名前}` で書けばだいたい動く」くらいの感覚で OK。迷ったら公式ドキュメントで確認する。

## デフォルト値のリセット（`initial`）

Tailwind が最初から持っている値（色・フォント等）を消して、使えるものを制限できる。

### 書き方

```css
@theme {
  --color-*: initial;  /* Tailwind デフォルトの色を全部消す */
}
```

`--{カテゴリ}-*: initial;` で、そのカテゴリのデフォルト値がすべて消える。

消した上で、必要なものだけ定義し直す。

```css
@theme {
  --color-*: initial;

  --color-white: #ffffff;
  --color-black: #000000;
  --color-gray-50: #f9fafb;
  --color-gray-100: #f3f4f6;
  --color-gray-600: #4b5563;
  --color-gray-800: #1f2937;
  --color-primary: #0ea5e9;
  --color-primary-light: #38bdf8;
  --color-primary-dark: #0284c7;
  --color-danger: #ef4444;
  --color-success: #22c55e;
}
```

これで `bg-indigo-500` 等は使えなくなり、定義したものだけが使える状態になる。

### 特定の色だけ消す場合

```css
@theme {
  --color-indigo-50: initial;
  --color-indigo-100: initial;
  /* ...50〜950 を全部書く必要がある... */
}
```

面倒なので、実務では「全部消して必要なものだけ定義」のほうがよく使われる。

## どこまでリセットするか

実務では**色とフォントくらい**。余白やサイズは基本リセットしない。

### 理由：間違えたときのダメージが違う

| カテゴリ | 間違えたときの影響 | `initial` するか |
|---|---|---|
| 色 | ブランドが崩れる。一目でわかる | ほぼする |
| フォント | 見た目が変わる。気づきやすい | することもある |
| フォントサイズ | 少しずれる程度 | ほぼしない |
| 余白（margin / padding） | 微差。デザインは崩れにくい | しない |
| 角丸・影 | 微差 | しない |

色はブランドに直結するので「`indigo` を勝手に使われたら困る」が起きる。でも余白で「`p-5` じゃなくて `p-6` を使われた」は大事故にはならない。

### 余白やサイズを制限しない理由

- Tailwind のデフォルトの余白スケール（`0, 1, 2, 3, 4, ...`）は十分に整理されていて、業界的にも広く使われている。消して再定義しても、ほぼ同じものになる
- 余白を厳しく制限すると「あと 2px ずらしたいのに使える値がない」が頻発し、開発速度が落ちる
- 色と違って余白は「正解が 1 つ」ではないので、ある程度の自由度があったほうが実用的

### 実務での典型パターン

```css
@import "tailwindcss";

@theme {
  /* 色だけリセットして定義し直す */
  --color-*: initial;
  --color-white: #ffffff;
  --color-black: #000000;
  --color-gray-50: #f9fafb;
  --color-gray-100: #f3f4f6;
  --color-gray-600: #4b5563;
  --color-gray-800: #1f2937;
  --color-primary: #0ea5e9;
  --color-primary-light: #38bdf8;
  --color-primary-dark: #0284c7;
  --color-danger: #ef4444;
  --color-success: #22c55e;

  /* フォントは必要なら変える（リセットしなくても上書きで OK） */
  --font-sans: "Noto Sans JP", sans-serif;

  /* 余白・サイズ・角丸等はデフォルトのまま使う */
}
