# 環境構築の手順

## 前提

Node.js がインストールされている必要がある。

```bash
node -v
```

バージョンが表示されれば OK。表示されなければ先に Node.js をインストールする。

## 手順

### 1. プロジェクトフォルダで npm を初期化

```bash
npm init -y
```

`package.json` が生成される。これは「このプロジェクトで使っている npm パッケージの一覧表」。
Python でいう `requirements.txt` に相当する。

`-y` は全ての質問にデフォルトで回答するオプション。学習用なら全部デフォルトで問題ない。

### 2. Tailwind をインストール

```bash
npm install tailwindcss @tailwindcss/cli
```

`node_modules/` フォルダが生成され、パッケージの実体が入る。
Python でいう `venv/` に相当する。

### 3. input.css を作成

```css
@import "tailwindcss";
```

input.cssの中にこれだけ書く。このファイルの役割は [ビルドとファイル構成](./ビルドとファイル構成.md) を参照。

### 4. HTML で output.css を読み込む

Tailwind を使用する HTML ファイルの `<head>` に、ビルドで生成される output.css を読み込む記述を追加する。

```html
<link href="output.css" rel="stylesheet" />
```

ファイル名は index.html でなくても構わない。Tailwind のクラスを使っている HTML であれば何でも OK。
読み込むのは `output.css`（ビルドで生成される完成品）であって `input.css` ではない点に注意。

### 5. ビルド

```bash
npx @tailwindcss/cli -i input.css -o output.css
```
