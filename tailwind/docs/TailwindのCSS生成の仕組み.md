# Tailwind の CSS 生成の仕組み

## なぜ CDN で配布しづらいのか

Bootstrap は完成した CSS ファイルを CDN で配布できる。
Tailwind はそれが難しい。理由はクラスの組み合わせ数にある。

### Bootstrap の場合

`.btn`、`.card` 等のクラスがあらかじめ全部定義されている。
数が限られているので、全部入りの CSS ファイル（約 200KB）を配布できる。

### Tailwind の場合

ユーティリティクラスの組み合わせが膨大。

**色だけでも：**

- 約 22 色 × 11 シェード = 約 240 色
- それが `bg-`、`text-`、`border-`、`ring-` 等のプロパティごとにある
- 色関連だけで約 1,680 クラス

**余白だけでも：**

- 約 30 段階 × 7 方向（p, px, py, pt, pr, pb, pl）= 約 210 クラス（padding だけ）
- margin も同じ数 → 合計約 420 クラス

**さらにバリアント（修飾子）が掛け算される：**

```
hover:bg-sky-500         ← ホバー時
focus:bg-sky-500         ← フォーカス時
md:bg-sky-500            ← 画面幅 md 以上
dark:bg-sky-500          ← ダークモード時
dark:hover:bg-sky-500    ← 組み合わせもできる
```

バリアントは約 30 種類以上あり、組み合わせも可能。

```
基本クラス数（数千）× バリアント（30種以上）× バリアントの組み合わせ
        ↓
    数十万〜数百万通り
```

全部入りの CSS ファイルにしたら **数十 MB** になる。現実的ではない。

## 「使った分だけ生成する」仕組み

Tailwind の CLI は HTML ファイルを見て、実際に使われているクラスだけを検出し、そのぶんの CSS だけを生成する。

```
HTML に bg-sky-500 と hover:bg-sky-600 と text-white がある
        ↓
CLI がそれを検出
        ↓
その 3 クラス分の CSS だけ生成 → 数KB
```

使っていないクラスの CSS は存在しない。だから軽い。

## CDN 版は使えるが本番向きではない

Tailwind にも CDN 版はある。

```html
<script src="https://cdn.tailwindcss.com"></script>
```

ただしこれは JavaScript がブラウザ上でリアルタイムに CSS を生成する仕組み。

| 方式                   | 仕組み                        | 本番利用                |
| ---------------------- | ----------------------------- | ----------------------- |
| CDN（`<script>` タグ） | ブラウザ上で JS が CSS を生成 | ❌ 重い。学習・試作専用 |
| CLI（ビルド）          | 事前に CSS ファイルを生成     | ⭕️ 軽い。本番向き       |

学習目的なら CDN でも問題ない。本番では CLI を使う。
