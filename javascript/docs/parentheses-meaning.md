# `( )` の意味の見分け方

JavaScriptの `( )` は、書く場所によって意味が変わる。

## 結論

- **定義しているところ** → `( )` の中は **名前の宣言**
- **使用しているところ** → `( )` の中は **値を渡している**

## 例

```js
// 定義側 → 名前の宣言
function greet(name) { ... }   // name は引数の名前
catch (e) { ... }              // e はエラーを受け取る名前

// 使用側 → 値を渡す
greet("田中");                 // "田中" という値を渡す
console.log("hello");          // "hello" という値を渡す
```

## 補助の見分け方

ぱっと見で判断したい時は、**`( )` の後ろに `{ }` があるか** で見分けられる。

| 形                | 意味              |
| ----------------- | ----------------- |
| `何か( ) { ... }` | 定義 → 名前の宣言 |
| `何か( )`         | 使用 → 値を渡す   |

※ まとめてから思ったが、ものすごく当たり前のことかもしれない
