# jsで関数を定義する時どの方法がいいか？

JavaScriptには関数を定義する書き方が3種類あるのでその中でどれがいいのかについて

## 書き方(3種)

```js
// 1. 関数宣言（function declaration）
function orya(a) {
  return a * 2;
}

// 2. 関数式（function expression）
const mya = function (a) {
  return a * 2;
};

// 3. アロー関数
const mya = (a) => a * 2;
```

## 結論

- **基本はアロー関数でOK**
- 関数宣言もたまに使う(トップレベルの関数など)
- 関数式は実質アロー関数の下位互換で、新規コードではほぼ使わない

## それぞれの立ち位置

| 書き方     | 特徴                                                           |
| ---------- | -------------------------------------------------------------- |
| 関数宣言   | 標準の形。巻き上げが効くのと、名前が重複した時に上書きされる。 |
| 関数式     | 変数に関数を入れる形。                                         |
| アロー関数 | 関数式の進化版。簡単に書ける                                   |

## なぜアロー関数が基本なのか

### 短く書ける（簡単）

```js
// 関数式
const add = function (a, b) {
  return a + b;
};

// アロー関数
const add = (a, b) => a + b;
```

### 同名で再宣言するとエラーになる

同名関数を書いた時に気付ける。

```js
const add = (a, b) => a + b;
const add = (a, b) => a * b; // ❌ エラーで気付ける

function add(a, b) {
  return a + b;
}
function add(a, b) {
  return a * b;
} // ⚠️ 上書きされる
```

### thisが勝手に変わらない

普段のコード（コールバック、データ加工など）では `this` を使わない場面が圧倒的に多い。
アロー関数は `this` が変わらないので、余計なことを気にせず書ける。

```js
// 通常の関数: 実行場所のthisを参照するためthisに何が入るかわからない。
setTimeout(function () {
  console.log(this); // 何を指すか分かりにくい
}, 1000);

// アロー関数： 定義した場所のthisを見るためthisには常に一定の値が入る
setTimeout(() => {
  console.log(this); // 定義した場所のthisのまま
}, 1000);
```

実行場所の`this` を使用したい場合は通常の関数を使うといい。

## 関数宣言はどんな時に使う？

- ファイルのトップレベルに置く「メインの関数」
- ユーティリティ関数
- 巻き上げを活かしてファイルのどこからでも呼びたい時

```js
function main() {
  // ...
}

function formatDate(date) {
  // ...
}
```
