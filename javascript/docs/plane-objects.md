# プレーンオブジェクトについて

## ドット記法とブラケット記法

オブジェクトの値を取り出す方法は2つある。

```js
let user = { name: "田中", age: 24 };

user.age; // ドット記法
user["age"]; // ブラケット記法
```

```js
let key = "age";
user[key]; // key が "age" に評価される → user["age"] と同じ
```

## 「全部ブラケット記法でよくない？」という疑問への結論

- ドット記法は、変数による動的なキー指定が構文的にできないからこそ、ドットを見た瞬間に「ここは固定のキーを取っているだけ。動的な仕掛けは無い」と確定できるので読みやすい。気がする。

## 呼び方
キーと値を合わせたペアを**プロパティ**と呼び
キーのことを**プロパティ名**とも呼ぶことがある
