# 演算子について

## 演算子とは

値をもとになんらかの処理を行い、その結果を返す記号のこと。(例:+とか-とか)
演算子によって処理される値は**オペランド(operand)**という。

## 優先順位について

演算子の処理は左から右へ順番に処理されていくのではなく、**優先順位**に沿って計算されてく。

### 優先順位表(AI作成)

上にあるものほど優先順位が高い(先に処理される)。
※ 覚える必要はない。こういうものがあると理解しておこう

| 優先 | 種類                           | 演算子                  | 結合性 |
| :--: | ------------------------------ | ----------------------- | ------ |
|  高  | グループ化                     | `( )`                   | -      |
|  ↑   | メンバーアクセス・関数呼び出し | `.` `[ ]` `( )`         | 左     |
|  ｜  | 単項・論理否定                 | `!` `-`(符号) `typeof`  | 右     |
|  ｜  | べき乗                         | `**`                    | 右     |
|  ｜  | 乗除算・剰余                   | `*` `/` `%`             | 左     |
|  ｜  | 加減算                         | `+` `-`                 | 左     |
|  ｜  | 比較                           | `<` `<=` `>` `>=`       | 左     |
|  ｜  | 等価                           | `===` `!==` `==` `!=`   | 左     |
|  ｜  | 論理AND                        | `&&`                    | 左     |
|  ｜  | 論理OR                         | `\|\|`                  | 左     |
|  ｜  | null合体                       | `??`                    | 左     |
|  ↓   | 三項(条件)                     | `? :`                   | 右     |
|  低  | 代入                           | `=` `+=` `-=` `*=` など | 右     |

> 「結合性」は、同じ優先順位の演算子が並んだときにどちらから処理するかを表す。
> 例:`10 - 3 - 2` は左結合なので `(10 - 3) - 2`、`2 ** 3 ** 2` は右結合なので `2 ** (3 ** 2)`。
