# プレースホルダーの理解

## プレースホルダーとは

プレースホルダーは、入力欄の中に薄く表示される補助テキスト。
主な役割は、入力例や形式のヒントを軽く示すこと。

ただし、ラベルの代わりに使うものではない。

```html
<label for="name">ユーザー名</label>
<input id="name" type="text" placeholder="例：yamada_taro" />
```

この場合、`ユーザー名` はラベルで伝わっているので、プレースホルダーには入力例を書く方がよい。

## 基本方針

プレースホルダーは、基本的に必要な項目にだけ使う。

理由は、すべての入力欄にプレースホルダーを入れると画面がごちゃつきやすく、どのヒントが重要なのか分かりにくくなるため。

特に、入力項目が多い画面では、全部の項目に例や説明を入れると、かえって見づらくなる。

```html
<label for="part-number">品番</label> <input id="part-number" type="text" />
```

品番のように、ラベルだけで入力内容が分かるものには無理にプレースホルダーを入れない。

## 使うなら入力例を書く

プレースホルダーを使う場合は、基本的に入力例を書く。

```html
<label for="postal-code">郵便番号</label>
<input id="postal-code" type="text" placeholder="例：123-2222" />
```

```html
<label for="lot-number">ロット番号</label>
<input id="lot-number" type="text" placeholder="例：LOT-202606-001" />
```

入力形式が分かりにくいものや、実際の値を見た方が判断しやすいものに使う。

## ルールはプレースホルダーに書かない

入力ルールは、基本的にプレースホルダーではなく、入力欄の近くに常時表示する。

理由は、プレースホルダーは入力し始めると消えるため。
ユーザーが入力中に確認したい情報ほど、消えてしまう場所に置かない方がよい。

```html
<label for="part-number">品番</label>
<input id="part-number" type="text" placeholder="例：PRD-001" />
<p>大文字英数字とハイフンのみ・10文字以内</p>
```

このように、プレースホルダーには入力例を書き、入力中も見えてほしいルールは補足テキストとして出す。

## 短いルールならラベルに含めた方が見やすい

短くて、その項目の意味に直結するルールであれば、ラベルに含めてもよい。

```html
<label for="part-number">品番（10文字以内）</label>
<input id="part-number" type="text" placeholder="例：PRD-001" />
<p>大文字英数字とハイフンのみ</p>
```

向いている例は以下。

- `品番（大文字のみ）`
- `数量（個）`
- `重量（kg）`
- `郵便番号（ハイフンなし）`
- `製造日（YYYY/MM/DD）`

ただし、長い説明をラベルに入れると読みにくくなる。
その場合は、ラベルと補足テキストに分ける。

## 役割の整理

| 要素             | 役割                                   |
| ---------------- | -------------------------------------- |
| ラベル           | 何を入力する欄かを示す                 |
| プレースホルダー | 入力例を示す                           |
| 補足テキスト     | 入力中も見えてほしいルールや注意を示す |

## まとめ

プレースホルダーは、親切に見えるからといって全項目に入れるものではない。

基本は必要な項目にだけ使う。
使うなら、迷いやすい項目に入力例を書く。
入力中も見えてほしいルールは、プレースホルダーではなくラベルや補足テキストで示す。
