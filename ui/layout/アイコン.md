# アイコン

アイコンは、文字だけでは見つけにくい情報や操作を、直感的に見つけやすくするために使う。

アイコンがあると、画面がわかりやすくなったり、とっつきやすく見えたりする。
ただし、アイコンの意味は人によって受け取り方が違うことがある。

そのため、基本的にはアイコンとテキストをセットで使う。

```text
🏠 ホーム
🔍 検索
⚙ 設定
```

アイコンだけよりも、テキストがある方が意味を判断しやすい。
特に、ナビゲーションや主要な操作では、アイコンとテキストをセットにした方が迷いにくい。

## アイコン単体で使える場合

基本はアイコンとテキストをセットにする。

ただし、意味がかなり定着しているアイコンなら、テキストを省略できることもある。

例えば、次のようなアイコン。

- 虫眼鏡: 検索
- 家: ホーム
- 歯車: 設定
- 三本線: メニュー
- バツ: 閉じる

ただし、アイコン単体で伝わるかどうかは、アイコンの形だけではなく、置かれている場所や文脈にも左右される。

例えば、ページの右上や左上に三本線のアイコンがあれば、メニューを開くものだと判断しやすい。
このような場所に、わざわざ「メニュー一覧」とテキストを付けると、画面がごちゃごちゃすることがある。

この場合は、アイコン単体で見せる方がすっきりする。

```md
アイコン単体でもよい場合:
意味が一般的に定着している
置かれている場所から用途を推測しやすい
テキストを付けると画面が重くなる
アイコンが小さく、補助的な操作として置かれている
```

逆に、意味が複数に解釈されそうなアイコンや、初めて見る人が迷いそうなアイコンは、テキストを付けた方がよい。

## 同じ意味には同じアイコンを使う

同じサービスや画面の中では、同じ意味には同じアイコンを使う。

例えば、検索を表すなら虫眼鏡、設定を表すなら歯車のように決める。

```md
検索: 虫眼鏡
設定: 歯車
ホーム: 家
メニュー: 三本線
```

同じ意味なのに別々のアイコンを使うと、ユーザーは「これは別の機能なのか」と感じやすい。

例えば、ある画面では虫眼鏡を検索に使い、別の画面ではフィルターや絞り込みに使うと、意味がぶれてしまう。

逆に、同じアイコンを違う意味で使うのも避ける。
同じアイコンが出てきたら、ユーザーは同じような意味や操作だと考えるため。

アイコンは、見た目の飾りではなく、意味を伝える記号として扱う。
そのため、同じ意味には同じアイコン、違う意味には違うアイコンを使う。

## アイコンの見た目のルールを揃える

アイコンは、種類だけでなく見た目のルールも揃える。

見るポイントは、主に次のようなもの。

- 線の太さ
- 角の丸さ
- 塗りアイコンか線アイコンか
- サイズ
- 余白
- 色

例えば、線が細いアイコンと、塗りつぶしの強いアイコンが同じ場所に並ぶと、片方だけ目立って見える。
意味の優先度とは関係なく、見た目の強さだけで目立ってしまう。

そのため、同じグループの中ではアイコンのデザインルールを揃える。

```md
よい例:
すべて線アイコン
線の太さが同じ
サイズが同じ
色の使い方が同じ

よくない例:
線アイコンと塗りアイコンが混ざっている
一部だけ線が太い
一部だけサイズが大きい
一部だけ色が強い
```

アイコンで個性を出す場合も、意味を変えるのではなく、見た目のトーンで出す。

例えば、ホームを表すなら、基本的には家のアイコンを使う。
ここで個性を出そうとして、玄関や表札のようなアイコンにすると、何を表しているのかわかりにくくなる。

個性は、アイコンの種類ではなく、線の雰囲気や角の丸さ、色、全体のアイコンセットの統一感で出す。

## アイコンのサイズとクリック範囲は別で考える

アイコン自体のサイズと、クリックできる範囲は別で考える。

アイコンは小さくてもよいが、押せる範囲まで小さくすると操作しにくい。

```md
アイコンの見た目:
16px、20px、24px など

クリック範囲:
アイコンより広めに取る
```

特にスマホでは、指で押すため、クリック範囲が小さいとタップしづらい。
見た目のアイコンが小さくても、ボタンとしての範囲は余白を含めて広く取る。

例えば、閉じるアイコンが16pxでも、押せる範囲はその周りの余白を含めて大きくする。

```text
[   ×   ]
```

このようにすると、見た目はすっきりしたまま、操作しやすくなる。

アイコンを使うときは、見た目のサイズだけでなく、実際に押しやすい範囲になっているかも確認する。

## まとめ

アイコンは、意味や操作を見つけやすくするために使う。

基本は、アイコンとテキストをセットにする。
ただし、意味が定着していて、配置からも用途がわかり、テキストを付けると画面が重くなる場合は、アイコン単体でもよい。

同じ意味には同じアイコンを使い、同じアイコンを別の意味で使わない。

また、アイコンの見た目のルールを揃える。
線の太さ、塗りか線か、サイズ、余白、色がばらばらだと、意味とは関係ないところで目立ち方に差が出てしまう。

アイコン自体のサイズとクリック範囲は別で考える。
見た目は小さくても、押せる範囲は十分に広く取る。
