# フッター

フッターは、ページの下部にある領域。

フッターには、補助的な情報やリンクを置くことが多い。

ヘッダーは、主要なページへ移動するためのナビゲーションとして使われることが多い。

一方でフッターは、ヘッダーに置くほどではないが、必要な人が探せるようにしておきたい情報をまとめる場所として使われる。

例えば、次のような情報を置くことがある。

```text
会社情報 / 利用規約 / プライバシーポリシー / お問い合わせ / SNSリンク
```

この場合、ユーザーは「運営元の情報があり、規約があり、問い合わせもできる」と把握しやすい。

また、言語切り替えやSNSリンクなど、全ページ共通で置いておきたいものを配置することもある。

つまり、フッターには、次のような役割がある。

- 補助的なページへ移動しやすくする
- 全ページ共通で必要な情報を置く
- ヘッダーに置ききれない情報をまとめる

## 自由に使われやすい

ヘッダーは、主要なナビゲーションの置き場として使われることが多い。

一方でフッターは、サイトやアプリによって置かれる内容が変わりやすい。

例えば、サービスサイトでは会社情報や問い合わせ先を置くことが多い。

メディアサイトでは、カテゴリ一覧やSNSリンクを置くことがある。

多言語サイトでは、言語切り替えを置くこともある。

置く内容は違っても、基本的には補助的な情報や導線をまとめるための場所。

## まとめ

フッターは、ページ下部にある補助的な情報やリンクの置き場。

ヘッダーほど重要ではないが、必要な人が探せる情報を置く。

会社情報、利用規約、お問い合わせ、SNSリンク、言語切り替えなどを置くことがある。

フッターはサイトやアプリによって自由に使われやすいが、基本的には補助的な情報や導線をまとめる役割がある。
