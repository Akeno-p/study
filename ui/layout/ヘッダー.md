# ヘッダー

ヘッダーは、ページの上部にある領域。

ヘッダーには、基本的に主要なナビゲーションを置くことが多い。

ナビゲーションがあると、ユーザーは行きたいページへ移動しやすくなる。

また、ナビゲーションを見ることで、そのサイトやアプリが何を扱っているのかも理解しやすい。

例えば、次のようなナビゲーションがあるとする。

```text
商品 / 料金 / 導入事例 / ヘルプ / お問い合わせ
```

この場合、ユーザーは「商品があり、料金があり、導入事例があり、問い合わせもできるサイトなんだ」と把握しやすい。

つまり、ヘッダーのナビゲーションには、次のような役割がある。

- 主要なページへ移動しやすくする
- サイトやアプリの全体像を伝える
- どんな情報を扱っているのかを見せる

## 左側に置く場合もある

ナビゲーションは、ページ上部のヘッダーではなく、左側に置く場合もある。

例えば、管理画面やアプリ型のUIでは、左側のサイドバーにナビゲーションを置くことが多い。

```text
ダッシュボード
商品管理
注文管理
ユーザー管理
設定
```

置く場所は違っても、やっていることは基本的に同じ。

主要なページへ移動しやすくし、サイトやアプリの構造を理解しやすくするためのもの。

```md
上部にある場合:
ヘッダー、グローバルナビ

左側にある場合:
サイドバー、サイドナビ
```

## まとめ

ヘッダーには、主要なナビゲーションを置くことが多い。

ナビゲーションがあると、ユーザーは行きたいページへ移動しやすい。
また、そのサイトやアプリが何を扱っているのかも理解しやすい。

ナビゲーションは上部ヘッダーに置くこともあれば、左側のサイドバーに置くこともある。

場所は違っても、主要ページへ移動しやすくし、全体像を伝えるという役割は同じ。
