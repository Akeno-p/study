# コンテンツの区切り方

画面の中に複数の情報があるときは、どこからどこまでが1つのまとまりなのかをわかりやすくする必要がある。

そのために使うのが、コンテンツの区切り方。
区切り方には、主に次のような方法がある。

- 余白を開ける
- 区切り線を引く
- 背景色を変える
- 線で囲う
- 影をつける

## 基本は余白で区切る

まずは、余白で区切れるかを考える。

余白は、線や背景色のような見た目の要素を増やさずに、まとまりを作ることができる。
そのため、見た目が軽くなりやすく、画面もごちゃつきにくい。

例えば、見出しと本文のまとまりを並べる場合は、余白だけで十分に区切れることが多い。

```text
見出し
本文

見出し
本文

見出し
本文
```

逆に、すべてを線で囲ったり、すべてに背景色をつけたりすると、画面内の要素が全部強く主張して見える。
その結果、情報量が多く感じられて疲れやすくなる。

だから、基本は次の順番で考えるとよい。

```md
まず余白で区切る。
余白だけでわかりにくいときに、区切り線・背景色・囲いを使う。
```

## 区切り方の種類

### 余白

余白は、いちばん自然で軽い区切り方。

関連が近いものは近くに置き、関係が少し離れるものは余白を広く取る。
これだけでも、ユーザーは情報のまとまりを理解しやすくなる。

ページヘッダーと本文の間、見出しと次の見出しの間などは、余白で区切るときれいに見えやすい。

### 区切り線

区切り線は、境界をはっきり見せたいときに使う。

余白だけでは区切りが弱いときや、同じ形式の情報が連続して並ぶときに向いている。

例えば、次のような場所で使いやすい。

- リストの行同士
- テーブルの行や列
- 設定画面の項目同士
- ヘッダーとコンテンツの境界

ただし、区切り線が多すぎると画面が細かく分断されて見える。
線は便利だが、使いすぎると情報量が多く感じられる。

### 背景色

背景色を変えると、面でコンテンツを区切ることができる。

線よりも広い範囲に影響するので、セクション全体を分けたいときや、まとまりを少し強く見せたいときに使いやすい。

例えば、次のような場所で使いやすい。

- ページ内の大きなセクション分け
- カード表示の背景
- 注意事項や補足情報
- 通常の情報と少し違う情報の区別

背景色は、濃さや彩度によって印象が大きく変わる。
デフォルトの背景色とほとんど同じ薄い色なら、かなりシンプルに見える。
逆に、濃い色や彩度の高い色を使うと、かなり強い区切りになる。

### 線で囲う

線で囲うと、その中の情報が1つのまとまりとして見えやすくなる。

カード、フォームの入力エリア、独立した情報ブロックなどに向いている。

ただし、すべてを囲うと画面が重く見える。
囲いは「これは1つの独立したまとまりです」と強く伝える方法なので、本当にまとまりとして見せたい場所に使う。

### 影

影は、要素を背景から浮かせて見せるために使う。

カード、モーダル、ドロップダウンなど、他の要素より前に出ているように見せたいときに向いている。

ただし、影も強い表現なので使いすぎると画面がうるさくなる。
背景色、囲い、影を全部使うとかなり主張が強くなるので注意する。

## 区切りの強さで考える

「区切り線だから弱い」「背景色だから強い」と固定で考えるのは少し違う。

区切り線にも、薄い区切り線とはっきりした区切り線がある。
背景色にも、かなり薄い背景色とはっきりした背景色がある。

例えば、薄いグレーの背景色は、黒に近い区切り線よりも弱く見えることがある。
逆に、太くて濃い区切り線は、薄い背景色よりも強く見える。

大事なのは、どの方法を使っているかではなく、どれくらい視覚的に目立つ区切りになっているか。

区切りの強さは、例えば次のように考えられる。

```md
余白
↓
かなり薄い背景色
↓
薄い区切り線
↓
少し濃い背景色
↓
はっきりした区切り線
↓
はっきりした背景色
↓
線で囲う
↓
背景色 + 囲い + 影
```

この順番は絶対ではない。
色の濃さ、線の太さ、余白の広さ、影の強さによって印象は変わる。

区切りの強さを決める要素には、次のようなものがある。

- 余白の広さ
- 線の濃さ
- 線の太さ
- 背景色の差
- 囲いの有無
- 影の有無

## 役割ごとに区切り方を統一する

コンテンツの区切り方は、システム内である程度統一した方がよい。

ただし、すべてを同じ方法で区切る必要はない。
大事なのは、同じ役割・同じ階層のものには同じ区切り方を使うこと。

例えば、次のようにルールを決める。

- ページヘッダーと本文の区切りは、余白で区切る
- システム内のカード表示は、背景色や枠で区切る
- リストの行同士は、薄い区切り線で区切る
- 入力フォームのグループは、余白と見出しで区切る
- 注意事項やエラーは、背景色で目立たせる

こうすると、ユーザーは見た目の意味を理解しやすい。

例えば、いつもカードが背景色で区切られているなら、ユーザーは「背景色が違うこの部分は、1つのまとまりなんだな」と判断できる。

逆に、同じ役割のカードなのに、ある場所では背景色、別の場所では枠線、別の場所では余白だけになっていると、何か意味の違いがあるように見えてしまう。

つまり、統一するのは「全部同じ区切り方にすること」ではない。
統一するのは、「この種類のまとまりにはこの区切り方を使う」というルール。

## まとめ

コンテンツを区切る方法には、余白、区切り線、背景色、囲い、影などがある。

基本は、まず余白で区切る。
余白だけでわかりにくいときに、区切り線や背景色を使う。
さらに強くまとまりを見せたいときに、囲いや影を使う。

ただし、「区切り線だから弱い」「背景色だから強い」と決めつけるのではなく、視覚的な強さで考える。

また、区切り方は役割ごとに統一する。
同じ役割・同じ階層のものには同じ区切り方を使うことで、画面に統一感が出て、ユーザーも情報のまとまりを理解しやすくなる。
