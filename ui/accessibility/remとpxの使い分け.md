# なぜ px より rem の方がアクセシビリティ的に良いのか

**rem はユーザーが設定したブラウザの文字サイズを基準にするから**。
px はそれを無視してしまうため、文字を大きくして読みたい人を締め出してしまう。


## px と rem の違い

- **px（ピクセル）**… 絶対単位。`16px` と書いたら、何があっても 16px で固定される。
- **rem（root em）**… 相対単位。**ルート要素（`<html>`）の文字サイズを基準**にした倍率。
  - ブラウザの初期値は `html { font-size: 16px }` なので、`1rem = 16px`、`1.5rem = 24px`。

ポイントは「rem は最終的な見た目を**ユーザー設定との掛け算**で決める」という点。

## ズームがあるから px でもいいのでは？

ピンチズームやブラウザズーム（Ctrl + +）などとフォントサイズ設定は話が別

- **ズーム**… 画面全体（レイアウトごと）を拡大する。横スクロールが発生しやすい。
- **フォントサイズ設定**… 文字だけを大きくする。レイアウトは保ったまま読みやすくできる。

「レイアウトは崩さず文字だけ大きくしたい」という細かなニーズに応えられるのは rem。
ズームは万能ではなく、フォントサイズ設定を尊重できることに固有の価値がある。

## まとめ

- px は絶対値なので、ユーザーのブラウザ文字サイズ設定を**無視する**。
- rem はルート基準の相対値なので、その設定を**尊重して追従する**。
- だから「文字を大きくして読みたい人」を取りこぼさない rem の方が、アクセシビリティ的に良いとされる。
