# ホバー表現

ホバー表現とは、マウスカーソルを要素に乗せたときに見た目を変える表現のこと。

ホバー表現があると、ユーザーはその要素が操作できるものだと直感的に理解しやすい。

## クリックできることを伝える

クリック可能な要素には、基本的に何かしらのホバー表現があった方がよい。

マウスカーソルを乗せたときに見た目が変わると、ユーザーは次のように判断できる。

- これは押せる
- これは選べる
- これは反応する
- ここは操作できる

例えば、次のような表現がある。

- ボタンの背景色が少し濃くなる
- リンクの文字色が変わる
- 下線が出る
- カードが少し浮く
- アイコンの色が変わる
- カーソルが `pointer` になる

このような反応があると、ユーザーは「ここは操作できる場所なんだ」と理解しやすい。

## ホバーは一時的な状態

ホバー状態は、今マウスカーソルが乗っていることを示す一時的な状態。

つまり、ホバーは「今触れている」「今操作できそう」という反応を伝えるもの。

ボタンを押した後の選択状態や、今見ているページを示すカレント状態とは意味が違う。

## 選択状態とは分ける

ホバー状態と選択状態は、別の見た目にした方がよい。

```md
ホバー状態:
今マウスカーソルが乗っていることを示す。
一時的な操作反応。

選択状態 / カレント状態:
今その項目が選ばれていることを示す。
現在地や選択中を表す継続的な状態。
```

この2つを同じ見た目にすると、ユーザーが混乱しやすい。

例えば、今トップページにいて、カレント表記として「トップ」の文字が青色になっているとする。

```text
トップ  ← 青文字。現在地
商品一覧
採用
```

このとき、商品一覧にホバーしたときも同じように青文字になると、青文字が2つになる。

```text
トップ    ← 青文字。現在地
商品一覧  ← 青文字。ホバー中
採用
```

これだと、ユーザーは「今トップにいるのか」「商品一覧を選択しているのか」がわかりにくい。

そのため、ホバー状態と選択状態は別の表現にする。

例えば、次のように分ける。

```md
選択状態:
青文字 + 太字

ホバー状態:
薄いグレー背景
```

または、次のように分ける。

```md
選択状態:
左に青い線 + 青文字

ホバー状態:
薄い青の背景
```

選択状態は「今選ばれている」ことを示すので、ホバーよりもはっきり見せる。
ホバー状態は「触れている」「操作できる」を示す一時的な反応なので、選択状態と区別できる範囲で弱めに表現するとよい。

## ホバーだけに頼らない

ホバーはPCでは便利だが、スマホやタブレットでは使えないことが多い。

スマホにはマウスカーソルがないため、ホバーしないと重要な情報や操作がわからないUIは避けた方がよい。

例えば、次のようなUIは注意が必要。

```md
ホバーしたときだけ削除ボタンが出る
ホバーしたときだけ詳細情報が見える
ホバーしたときだけリンクだとわかる
```

PCでは使いやすくても、スマホでは見つけにくくなることがある。

重要な操作や情報は、ホバーしなくてもわかるようにしておく。
ホバーはあくまで、操作できることを補強する表現として使う。

## まとめ

ホバー表現は、クリック可能なものを直感的に伝えるために重要。

クリックできる要素には、基本的にホバー時の見た目の変化を用意する。

ただし、ホバー状態と選択状態は別の意味を持つ。
ホバーは一時的な操作反応、選択状態は現在地や選択中を示す継続的な状態。

そのため、ホバーと選択状態を同じ見た目にしない。

また、ホバーはPC向けの表現なので、ホバーしないと重要な情報や操作がわからない状態にはしない。
